# Drop vertical clip videos here

Name the file exactly like in `assets/js/clips-data.js`, for example:

- `tts-title.mp4`
- `karaoke.mp4`
- `neon-box.mp4`
- `auto-cut.mp4`
- `dual-split.mp4`
- `emphasis-zoom.mp4`
- `title-drop.mp4`
- `punch-reveal.mp4`

Optional poster image with the same basename: `tts-title.jpg`

Then commit + push. The video will play inside the phone mockup automatically.

Prefer 9:16 exports. Keep each file reasonably small for GitHub Pages.
